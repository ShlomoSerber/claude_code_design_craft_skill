# Fonts and pairings

The archetypes assign four typographic roles: **headings**, **body**, **captions**, **data**. Fill each role with one family. All families below are on Google Fonts.

| Family | Character | Good for |
|---|---|---|
| Inter | neutral grotesque | body, UI, headings in product UI |
| Geist | crisp geometric grotesque | body, headings, UI |
| Funnel Sans | friendly humanist sans | headings, captions |
| Anton | condensed heavy display | monumental headlines only |
| Newsreader | editorial serif | headings, pull quotes, captions |
| Playfair Display | high-contrast serif | display headings |
| Geist Mono | mono | data, code, labels |
| IBM Plex Mono | mono with warmth | data, code, technical captions |

Rules: at most two families plus one mono. Use weight and size for hierarchy before adding a family. Never set body below 14px on web, 16px on mobile.
