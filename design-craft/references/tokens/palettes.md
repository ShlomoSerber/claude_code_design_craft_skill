# Color palettes

Every palette defines the same 17 semantic tokens. Archetypes reference tokens by name, so swapping a palette never changes structure. Contrast note: `foreground.*` values are chosen against `surface.primary`; re-check contrast when placing text on `surface.inverse` or on `accent.*` (use `foreground.inverse` there).
